# Capstone_1
## The core of this project is: 

I playing the role of a data analyst, analyzing sales data for a specific "sales territory" of a bookstore chain (EmporiUm),
writing SQL queries, creating an Excel chart,  and telling a story of my findings(finally presenting my findings through video and in-class presentation).

3. Export results to CSV for reporting.
4. Create a Pivot Chart to visualize findings.
5. Present results through a video demo and presentation.
6. Complete additional exploratory analysis when applicable.
